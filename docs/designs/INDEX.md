# Design documents

One document per planned or built feature. A design doc says what is being built, what it
proves, and **where it stops** — the last of those is the most re-read section and the one that
stops scope arriving by accident later.

**Edit these in place**, like ADRs. A decision taken *during* design work is an
[ADR](../decisions/INDEX.md), not a paragraph in here.

Start from [`DD-000-TEMPLATE.md`](DD-000-TEMPLATE.md). The sections that may not be dropped are
**what this proves**, **non-goals**, **measurements this must produce** and **where it stops**.
